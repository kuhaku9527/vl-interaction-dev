     - **门禁层** = fail-closed **存在性** + **解析完整性** + 决策承载**字面**（在 CI 的 `drift-gate` job 独立跑，`--phase static --mode closed`）；
     - **pytest 层** = canonical（`sort_keys=True`）sha256 **全量内容绑定**（覆盖全部叶子）。

     两者强度不同、覆盖面不同：门禁层跟着契约 check 的 pattern 走，pytest 层是整份产物的摘要。任一层都不能替另一层下结论。
