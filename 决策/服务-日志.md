## D-2026-08-01-060  日志事件 schema 锁定（JSONL 必填 4 字段）

- **事实**: 运行时事件统一落到 `logs/events/<service>-<UTC-YYYY-MM-DD>.jsonl`。必填字段 `ts` (ISO 8601 UTC) / `level` ∈ {debug,info,warn,error,critical} / `service` / `event` (kebab-case)。可选 `session_id` / `latency_ms` / `status` / `user` / `extra` (object)。单 service 单天单文件，按天滚动。
- **来源**: `doc/specs/log-event-schema.md`（v1.0，已批准 2026-08-01） + `doc/adr/0014-log-event-schema.md`（Accepted）
- **校验**: ⚠️ **本校验当前不可执行** —— `scripts/log_query.py` 从未落盘（2026-09-14 核查）。替代校验：`ls logs/events/*.jsonl` 且逐行 `python -c "import json,sys;[json.loads(l) for l in open(sys.argv[1],encoding='utf-8')]" <file>` 应为合法 JSON（注意：部分文件含 UTF-8 BOM，首行需 `encoding='utf-8-sig'`）。<!-- known-absent --> 原设计意图：`python scripts/log_query.py --service webui --since 1h` 返回 1 小时内 webui 所有事件；事件文件 `<service>-YYYY-MM-DD.jsonl` 存在且每行都是合法 JSON；4 必填字段都非空。
- **预期**: 4 字段必填；字段禁变（breaking 走 schema_version bump + 决策）；service 集合封闭 {webui, webinfer, memory-store, vllm-llama, launcher, drift-gate}。
- **Drift**: 无
- **Owner**: 审查组（Codex）
- **锁定**: 🔒

## D-2026-08-01-061  PII 红线（review 闸门）

- **事实**: 日志事件**不记**：(a) request/response body（含 chat 内容、memory-store push blocks）、(b) raw session key / API key / token、(c) 文件内容（仅记 path + size_bytes）、(d) client IP（除非安全审计场景）。`webui chat_request` 事件 extra **最多**含 `{message_chars: int, has_image: bool}`，**永远不**含 raw `text` / `image_b64`。
- **来源**: spec S-1 末尾的"PII 红线"段（"违反 = 拒绝合并"）
- **校验**: `grep -r "message_text\|text=\|password\|api_key" logs/events/` 命中 0；code review 卡 `extra={"text": ...}` 类提交；CI 加 lint rule 检测 `text=` 出现在 logger call。
- **预期**: 所有 PII 字段只能通过"长度 / 哈希 / 标志位"间接表达；任何 raw PII 落地即视为事故触发 DRIFT-7。
- **Drift**: 无
- **Owner**: 全员（任何写 logger call 的人）
- **锁定**: 🔒

## D-2026-08-01-062  Q1 老日志 → Q2 JSONL 迁移路径

- **事实**: 4 个 Q1 文件（`logs/drift-gate-history/` / `logs/launcher-*.log` / `logs/vlm-probes/` / `logs/webui-access-*.log`）继续作为**取证 / 历史**日志存在。`scripts/log_maintenance.ps1` 已覆盖 history 清理（commit `7118ebe`）。新 JSONL 事件流**双写**阶段至少持续 1 周 → Q1 文件标 deprecated → 1 个月后删除。本决策只规定**迁移窗口**，不强制关 Q1。
- **来源**: spec "Migration Plan (Q1 → Q2 路径)" 段
- **校验**: `git log --oneline a97ef08 822907b 1515054 0ddd390` 显示 4 个 Q1 commit 都已落；`scripts/log_maintenance.ps1 -HistoryRetentionDays 0` 列出 Q1 history 目录文件；`logs/events/<service>-<UTC>.jsonl` 在 spec 落地后存在且非空
- **预期**: 4 个 Q1 文件至少保留 1 周；JSONL events 优先用于新查询；`grep` Q1 仍能工作（不破坏现有故障排查流）
- **Drift**: 无
- **Owner**: 审查组
- **锁定**: 🔒
